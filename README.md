# pearkSoar Skills

面向 Codex 的个人技能集合。

## 已包含技能

- [`storage-analyzer`](storage-analyzer/)：macOS / Windows 只读存储分析助手，可生成可折叠的 HTML 报告。
- [`evidence-driven`](evidence-driven/)：证据驱动工程 Harness，用于长期 AI 协作开发、验证和跨会话接力。

## 安装

将需要的技能目录复制到用户级或仓库级 `.agents/skills/` 目录，然后在 Codex 中使用对应的技能名称调用。
